# 关节的活动范围

人能把每个关节转多大，从文献取值，给 `.blend` 绑定里控制骨上的旋转限制用（[关节极限的实现](../systems/blend.md#关节极限)）。数据在 [range-of-motion.json](../../sotaigen/data/range-of-motion.json)，每一项写着来源、原始数和量法；本文说怎么读、怎么换到骨骼上，以及还缺什么。

这里是**活动范围**，不是**干净范围**：前者是人做得到的，后者是我们的网格在多大角度内还好看（[关节的已知极限](../systems/rig.md#关节的已知极限)）。两者差得很远，比如上臂前抬的干净范围不到 30°，活动范围约 170°。

## 默认值

成人、取整，都从解剖中立位量起（立正、手臂下垂、掌心朝前）。详细的分性别、分年龄数和各来源的差别在 JSON 的 `detail` 和 `note` 里。

| 关节 | 动作 | 默认 | 来源 |
|---|---|---|---|
| 肩 | 前屈上举 | 170 | Soucie 2011（被动） |
| 肩 | 侧举上举 | 150 | Gill 2020（主动，20–91 岁平均） |
| 肩 | 内旋 / 外旋 | 60 / 83 | McKay 2017（主动） |
| 肘 | 屈 / 过伸 | 147 / 3 | Soucie 2011 |
| 前臂 | 旋前 / 旋后 | 80 / 88 | Soucie 2011 |
| 腕 | 屈 / 伸 | 75 / 65 | Fan 2019 |
| 腕 | 桡偏 / 尺偏 | 20 / 35 | Fan 2019 |
| 手指 | 掌指关节屈 / 过伸 | 85 / 25 | Mohamed Ibrahim 2024 |
| 手指 | 近节指间屈 / 过伸 | 95 / 15 | 同上 |
| 手指 | 远节指间屈 / 过伸 | 83 / 7 | 同上 |
| 髋 | 屈 / 伸 | 125 / 18 | Roaas 1982、Soucie 2011 |
| 髋 | 外展 / 内收 | 40 / 30 | Roaas 1982 |
| 髋 | 内旋 / 外旋 | 35 / 35 | Roaas 1982 |
| 膝 | 屈 / 过伸 | 140 / 1 | Soucie 2011 |
| 踝 | 背屈（屈膝负重） / 跖屈 | 40 / 55 | Konor 2012、Soucie 2011 |
| 踝 | 外翻 / 内翻 | 25 / 30 | Roaas 1982 |
| 颈 | 前屈 / 后伸 | 60 / 60 | McKay 2017 |
| 颈 | 侧屈 / 旋转（每侧） | 40 / 78 | Ferrario 2002 |
| 腰椎 | 前屈 / 后伸 | 60 / 20 | Troke 2005 |
| 腰椎 | 侧屈 / 旋转（每侧） | 25 / 7 | Troke 2005 |
| 胸椎（T1 对 L1） | 侧屈 / 旋转（每侧） | 16 / 25 | Fujimori 2014、2012 |
| 胸椎（T1 对 L1） | 屈到伸的总弧 | 32 | Morita 2014 |
| 下颌 | 张开（转动） / 侧移（每侧） | 27 / 5 | Krohn 2020、Škaričić 2020 换算 |
| 眼 | 上转 / 下转 | 38 / 58 | Gerling |
| 眼 | 内转 / 外转 | 52 / 49 | Gerling |

**怎么取的：** 来源之间的差别主要来自主动和被动、量的体位、人群和年龄。挡姿势的极限宁宽勿窄，所以有被动值时取被动，年龄取成人。髋伸原来写 15，比 CDC 成人的被动值（女 18.1、男 17.4）还紧，改为 18。踝背屈取屈膝负重的值：伸膝时跨膝的腓肠肌先拉紧，被动只有 13–18，而控制骨的极限不知道膝角，取伸膝的值会挡住所有下蹲；屈膝弓步时胫骨离竖直 38–40（Konor 2012，倾角计），取 40。同一动作各来源相差大的（髋伸 9–28、踝跖屈 40–62、踝背屈主动和被动差一倍），在 JSON 的 `note` 里写了。

**年龄和性别：** 孩子的范围普遍更大（如 2–8 岁肩前屈约 178、髋屈 131–141），女性大多比男性大几度，年长者变小。我们的典型身体从 Q版到成人都有，但这些身体的比例取自不同年龄，不代表角色的年龄，所以默认都用成人值；要按年龄或性别收放，`detail` 里有数。

**证据强度：** 用 [动态解剖卡](README.md#字段) 的分级。Soucie（CDC 页面上的表）、McKay（文中表 2）、Roaas（文中表 1，另列了 AAOS 手册和 Boone & Azen 1979 的值）、Konor（文中表 2）是读到原表的 `measured`；Škaričić（经 PubMed 读到全文）也是 `measured`，但它量的是磨牙症患者切牙点的毫米数，这里只借它的大小，换成角度的杠杆是估的；Gill、Fan、Mohamed Ibrahim、Ferrario、Troke、Gates、Fujimori、Morita、Krohn、Li、Gallagher、Gerling 只读到摘要，是 `snippet`。

## 还缺的

没有找到能读到原文的来源，JSON 里是 `null`：

- **肩后伸、肩水平内收：** 常见教科书值（AAOS 手册、Norkin & White）没能读到原文；Barnes 2001、Boone & Azen 1979 有，但都不开放。
- **拇指**（腕掌、掌指、指间）和**手指分开**（掌指关节外展）。
- **脚趾**（跖趾关节）。
- **胸椎**屈和伸各多少：Morita 2014 只有屈到伸的总弧 32°（被动，患者组），没有中立位的扫描，分不出两边。
- **远节指间关节的被动过伸：** 只有 Mohamed Ibrahim 的主动值 7，没找到被动值；`littleOpposition` 按它收到 −7。

能读到 AAOS 手册（*Joint Motion: Method of Measuring and Recording*，1965）或 Norkin & White 的人可以补上。

## 换到骨骼上

文献从解剖中立位量，我们的控制骨从静止姿势量，所以要换两样：轴和零点。轴和正方向先按 `sotaigen/rig/poses.py` 的检查姿势推出来，再在 Blender 里摆过（`tests/test_blend.py`，12 个典型身体的两侧）：都对，只有 `foot` 的 Y 反了，Y+ 是外翻。实际用的换算和零点见 [`.blend` 的关节极限](../systems/blend.md#关节极限)。

| 骨 | 局部轴 | 对应的动作 | 零点的差 |
|---|---|---|---|
| `upperArm` | X+ 前抬、X− 后伸；Z+ 侧举、Z− 收回；Y 滚转。极限按 YZX 分解读（[上臂的分解顺序](../systems/blend.md#上臂的分解顺序)） | 肩前屈 / 后伸、外展、内外旋 | 静止时已侧举 35°（[静止姿势](../DECISIONS.md#绑定与动作)），所以 Z 的上限是 150 − 35 = 115，下限 −35（垂下时贴身，水平时可越过中线 45°） |
| `lowerArm` | X+ 屈 | 肘屈、过伸 | 静止时前臂对上臂有约 4° 的外偏（提携角），不影响屈伸 |
| `hand` | X 屈伸、Z 桡尺偏、Y 前臂旋转 | 腕、前臂旋前旋后 | 静止时手掌朝向大腿、拇指朝前，就是前臂旋转的中立位；Y+ 旋前 |
| 手指 `*Proximal` / `*Intermediate` / `*Distal` | X+ 屈、X− 过伸；`*Proximal` 的 Z 分开 | 掌指、近节、远节指间 | 模板静止时手指微屈，但骨骼连的是关节中心，量出的静止角不可信（远节会是过伸 15–22°），所以暂不扣 |
| `upperLeg` | X+ 屈、X− 伸；Z 外展内收；Y 内外旋 | 髋 | 静止时两腿几乎平行 |
| `lowerLeg` | X− 屈 | 膝屈（`crouch` 是 −115）、过伸 | — |
| `foot` | X+ 背屈、X− 跖屈；Y+ 外翻、Y− 内翻（没有单独的骨，近似为绕脚的 Y） | 踝 | 静止时脚掌着地 |
| `spine`、`chest`、`upperChest` | X+ 前屈；Y 扭转；Z 侧屈 | `spine` 是腰椎，`chest` 是 T7–L1，`upperChest` 是 T1–T7 | 按骨头所在的高度分（见 [`.blend` 的关节极限](../systems/blend.md#关节极限)）；胸椎的扭转、侧屈按 Fujimori 量的各节之和分给上下两段 |
| `neck`、`head` | X+ 前屈（点头）；Y 旋转；Z 侧屈 | 颈 | 两根骨分摊，`headTurn` 是颈 15 加头 30 |
| `jaw` | X+ 张开，和点头同向；Z 下巴偏向一侧；Y 锁住 | 下颌 | 静止时闭着，所以闭合方向的极限是 0。前滑由 X 带出来，不是单独的通道（[张嘴卡](jaw.toml)） |
| `leftEye`、`rightEye` | X+ 上转、X− 下转；Z+ 朝穿着者左；Y 锁住 | 眼 | 静止时平视。左眼的 Z+ 是外转；右眼镜像，Z− 是外转 |

**肩胛：** 文献的肩前屈和侧举包含肩胛的参与。我们的控制骨转的是总量，肩胛自动分担 20%（[肩胛联动](../DECISIONS.md#绑定与动作)），所以极限加在上臂的控制骨上，用的就是总量。

**欧拉角近似：** Blender 的旋转限制按欧拉角逐轴卡，表达不了真实的锥形范围：比如手臂侧举到顶时还能不能再前抬，逐轴的限制不知道。真实动作上看过一次：按 XYZ 分解时上臂的贴身下限会挡住前抬时的滚转，所以上臂改按 YZX 分解（[上臂的分解顺序](../systems/blend.md#上臂的分解顺序)）。其余关节没有这样查过；伸髋 18° 会挡住走路的后腿，动作文件因此关极限（[真实动作](../systems/blend.md#真实动作)）。

## 日常动作要的范围

Gates 2016 量了八项日常上肢动作实际用到的范围（JSON 的 `functional`），比最大值小得多：上臂抬起 0–108°、肘屈 0–121°、腕屈伸 −40–38°、躯干扭转 32°。这可以作为[干净范围](../DECISIONS.md#绑定与动作)的下限目标：至少这些动作要好看。
