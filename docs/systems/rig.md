# 绑定与动作

骨骼、权重、检查姿势和真实动作。肩腋见[肩腋与胸侧](../parts/shoulder-axilla.md)，腹股沟见[腹部—大腿过渡](../parts/groin.md)，肘和手见[四肢](../parts/limbs.md)。

**还没解决：** 肩腋高侧举、深屈髋折痕与短颈大角度仰头仍需看图评估。关节的可用范围必须在当前身体和导出路径上复测，不能由活动范围或单项指标推断。

## 现状

骨架清单见[骨骼约定](../reference/skeleton.md)，每顶点最多 4 个影响。胯关节 X 从贴合后的网格量（见“胯关节 X 用膝环”）。腰以下的权重默认经过拟合（见“腰以下的权重拟合”）。绑定不变量在全部身体上由 `tests/test_rig.py` 把关。

检查姿势由 `sotaigen.rig.poses.POSES` 定义。塌面与折痕需按部位和动态卡判读，尤其检查下蹲的腹股沟、膝弯及抬臂的腋窝；旧身体的计数与看图结论不作为当前验收结果。

**指标：** `joints.json` 每个姿势有这三项。

- `legsPastMidline`：腿部顶点过中线数，按模板侧别算。只对检查姿势有意义：真实动作里骨盆会转，走路也有几百个顶点过中线，并不是穿插。
- `selfIntersections`：网格边穿过别处三角形的次数。三角形和边都取导出的三角网，边包括四边面的切分对角线。接触是真实的（肘弯、膝弯、手指入掌都算），所以不是越少越好，要看部位。
- `intersectionsByPair`：按部位分的次数，比如腋下是 `trunk|upperArm`，腹股沟是 `trunk|upperLeg`，`<>` 表示左右相对的肢体。静止基线记在 `restSelfIntersections`，应与同一身体、同一版本的姿势结果对照。

`girth` 每个姿势都量。姿势里的骨名给出局部转角，`rootTranslation` 单独给出世界坐标中的整体位移（毫米），省略时为零。Python 对未知骨名报错。

**下蹲接地。** `sotaigen.rig.poses.POSES["crouch"]` 提供各关节角度，`check_poses` 还会按体型补上整体位移，使两脚的平均前后位置回到站立处、最低脚底落在 Z=0。构建的 OBJ、指标和 GLB 内的 `checkPoses` 使用同一份姿势。该静帧没有重心或地面反作用力解算。

## 工具

都用 `uv run <脚本>.py` 运行，动作的在 `sotaigen_dev/motion/`，其余在 `scripts/`。

| 命令 | 作用 |
|---|---|
| `sotaigen_dev/motion/clips.py fetch` | 下载原始动作到 `build/reports/motions/raw/`，校验，缩减成 `motions/clips/*.json`（已提交） |
| `sotaigen_dev/motion/clips.py measure [身体 ...]` | 每段动作每帧的塌陷和穿插，取最差 |
| `sotaigen_dev/motion/clips.py sheet <身体> --clip walk --frames worst` | 动作的关键帧，走 `sotaigen_dev/review.py` |
| `sotaigen_dev/motion/clips.py hands <身体> -o out.png` | 手部姿势，含指腹捏取和握圆柱 |
| `sotaigen_dev/motion/clips.py contacts female-long --clip walk` | 测量约束前后支撑脚高度和帧间滑移（毫米） |
| `sotaigen_dev/motion/clips.py glb female-long --clip walk -o build/reports/motions/walk.glb` | 带世界位移、足部接触和辅助骨旋转的标准 GLB 动画 |
| `sotaigen_dev/motion/blend.py run female-long --clip walk` | 打成 `.blend` 控制骨的关键帧并读回对照，见 [`.blend` 的真实动作](blend.md#真实动作) |
| `sotaigen_dev/motion/hand_contacts.py female-long` | 测量双手的指腹朝向、间距、柱面余隙和手部自交 |
| `scripts/clean_range.py measure [身体 ...]` | 干净范围：每个关节单独扫角度，带默认修正形状，加手摸头、手靠近脸的组合姿势，写 `build/reports/clean-range/` |
| `scripts/clean_range.py summary` | 合并各身体的读数，打印每个关节每个角度的最差值，写 `first-worse.txt` |
| `scripts/clean_range.py sheets [--only 名字]` | 干净范围的看图拼图，每张一个视角，6 个女或 6 个男身体乘 clay、toon |

动作数据的来源和授权见 `motions/SOURCES.md`。

**左右对称：** 下半身拟合本身不对称：`vertex_frames` 取第一个邻点作切向，邻点顺序不镜像；`is_left = x >= 0` 又让中线顶点不能新增右侧骨骼。所以 `fit_lower_body` 的结果按镜像写回：右侧取左侧的镜像，中线取自身和镜像的平均，全部身体左右权重差小于 1e-12，`tests/test_rig.py` 的 `test_the_weights_mirror_across_the_midline` 守着。身体不对称时（镜像找不到对应顶点）不做镜像。

**腕和踝的融合边缘：** `END_BLEND` 的融合球外再过渡 `END_EDGE`（半径的 0.3）。硬边时拇指根折痕的顶点在有的身体上落在球内、有的落在球外，权重随手的大小跳变，拇指对小指时拇指根穿插；过渡带用于保持权重连续；拇指对掌仍须检查当前网格的穿插。

## 关节的已知极限

**干净范围**指网格在多大角度内仍符合视觉目标，不是人的活动范围；分工见 [DECISIONS](../DECISIONS.md#绑定与动作)。使用 12 个典型身体，灰模与 toon 分别查看正面、侧面及斜前、后斜视角。

**测法：** `scripts/clean_range.py measure` 从静止姿势逐关节扫角度，默认雕塑修正绑进静止皮肤后调用 `pose_verts`，不包含 IPC 接触表。输入是骨骼局部欧拉角；`neck` 与 `head`、`spine` 与 `chest` 各转输入角，合计为两倍。上臂实际方向还受肩带联动影响，不能直接把输入当作临床关节角。`foot` 正转是背屈。

每个角度记录塌陷面、相对静止新增的超过 90° 折边及分部位穿插。屈肘按[肘卡](../motion/elbow.toml)分预期折痕内外。`summary` 汇总首次变差的角度，`sheets` 生成拼图。指标只能定位问题；接触褶皱可能计为穿插，而肩部台阶可能完全不触发指标。可用范围须同时记录代码指纹、身体、修正路径、视角和看图结论。

### 组合动作的扫描

`clean_range.py measure` 还扫描手到头、手靠近脸等组合，`probes` 记录手到头部皮肤的最近距离和落点。固定角度不能适应所有头大小和臂长；需要实际接触目标时使用[触点](touch.md)。复合姿势须单独检查肩腋、肘弯和手部摆放。

**肘、膝加密：** 肘、膝两侧各加了 2 个环，肘的外侧折线变成圆弧（见[关节处的边环](../parts/limbs.md#关节处的边环)）。权重仍在加密前的网格上算，再插值到新顶点，所以过渡带的长度不变。肘背侧的转角另有来源：半转骨圆弧和背侧分别跟随两段肢体，见[肘尖](../parts/limbs.md#肘尖)。腹股沟和腋下不能仅凭环数判定拓扑已经足够；腋部还需检查贴合后的面片分布、结构分区和运动中的拉伸，见[肩腋与胸侧](../parts/shoulder-axilla.md)。

## 颈部的权重按毫米平滑

**做法：** `skin_weights` 在颈部按边数扩散之后，再在同一区域（颈段，加头部下巴以上 0.45 头高以内）解一次 `(I + r²Δ) w = w₀`，Δ 是每条边按长度平方倒数加权的网格拉普拉斯，`r = 0.10` 头高（`NECK_SMOOTH`），区域外的皮肤固定不动（`smooth_over_length`）。从头顶往下 0.9 头高以内的脸（`NECK_FACE`）不参加这次平滑，五官和耳不会在皮肤上滑动；嘴线以下再分给 `jaw`，见[下颌和眼骨](#下颌和眼骨)。只是权重，不加骨骼、约束或修正形状，所以导出、`web/runtime/driver.mjs` 和 `.blend` 自动一致。动态解剖卡见[颈](../motion/neck.toml)。

**依据与限制：** 短颈处的网格排距不均匀，单纯按边数扩散会让权重梯度集中在很短的物理距离内。按长度平滑将转动分布到颈段；半径过大又会把头部转动传到颈根，故使用局部的 0.10 头高范围。贴合还须保持合理排距，见[颈部的排](wrap-uv.md#颈部的排)。

验证应覆盖转头、点头、仰头、侧屈及组合姿势，包含短颈测试身体。大角度仰头仍可能压扁后颈面，不能从检查姿势通过推断整个活动范围可用。

## 骨骼约定

骨的名字、父子关系、顺序、局部轴和静止姿势是冻结的对外约定 ②，写在[骨骼](../reference/skeleton.md)，那里维护生成的骨骼表；金样是 `tests/contracts/bones.json`，`tests/test_contracts.py` 对每个典型和测试身体核对，失败就是约定被破坏，不是测试过时。

`jaw` 和两根眼骨位于表尾。骨骼顺序决定蒙皮列号和缓存含义，必须遵守冻结的骨骼约定。

## 下颌和眼骨

三根骨排在骨骼表的最后，所以其余骨骼的列号不变。放在哪、权重怎么算都在 `sotaigen/rig/skeleton.py` 的 `head_bones` 和 `jaw_share`，常量在文件开头。卡片和取舍见[张嘴](../motion/jaw.toml)，活动范围见[表](../motion/range-of-motion.md)。

**`jaw`：** 头在中线上，从头顶往下 0.63 头高、头轴上（`TMJ_T`、`TMJ_Y`，耳根之前、耳的下半段高度），尾在下巴。局部 X 是穿着者左，和 `head` 相同，所以 X+ 张开，方向和点头一样；局部 Y 指下巴。它不是肢段的“Z 朝前”，因为那样张开要写负角度。

**前滑：** 不是骨上的字段，记在骨架的 `glides` 里（`Skeleton.glides`，`skeleton.json` 的顶层），`jaw` 一项是每度张开的毫米数，在骨的静止坐标系里，`bone_local` 按 X 的正值乘上去，闭合方向不滑。方向沿关节结节向前下 35°（Krohn 2020 的髁道倾角平均 34.8°）。大小是骨长的 0.0125/度（`JAW_GLIDE`），20° 约 27 mm：按人的比例算是 0.005/度（转动占切牙运动的 77%，Sforza 2009），但这个头的下巴在关节下方多、前方少，下巴主要向后走，颏下被顶出尖棱，所以取 0.0125。

**权重（`jaw_share`）：** 只从 `head` 的权重里分，所以 `head + jaw` 等于原来的 `head`。分界是侧面看从关节到嘴线的斜线（`MOUTH_T` 0.828，嘴在关节前 0.30 头高），线以下归 `jaw`。渐变的宽度沿脸颊是 0.14 头高，到嘴前才收到 0.036，嘴角落在渐变中间，约走一半。往后在 0.10 头高内淡出，到耳根（头轴后 0.03 头高，`JAW_EAR_Y`）为 0，皮肤不会从耳根下滑走。颏下按到颈环平面的高度，0.18 头高内淡到 0，所以颈环和颈段逐点没有 `jaw`。t > 0.75（鼻下，`JAW_SMOOTH_BELOW`）的份额再按皮肤平滑 0.06 头高（`JAW_SMOOTH`，同[颈部](#颈部的权重按毫米平滑)的办法）。只平滑份额，`head` 和 `jaw` 的和保持不变；随后仍受最多四个影响的裁剪约束。最高到从头顶约 0.57 头高（靠耳前），额、眼的皮肤不动。鼻下的皮肤 20° 最多走 4 mm，耳根的皮肤最多 5 mm，鼻和耳是绑 `head` 的部件，所以张得大时那里会相对皮肤滑一点。

**眼：** 骨头在眼窝中心，是皮肤上虹膜处沿内法线进去 0.14 头高（`EYE_RADIUS`），再按下面的球调深度；尾在正前方，所以骨长就是球的半径。局部 Y 是视线，Z 朝上：X+ 上转，Z+ 朝穿着者左。没有皮肤权重。占位的虹膜、瞳孔、高光贴在这个球上（`sotaigen.output.face.eye_shell`），转动时留在同一个面上；球只在虹膜周围一块（`EYE_PATCH`，横向加 12° 的视线）露出皮肤，再往外沉到皮肤下面，所以上下看时虹膜被皮肤盖住，像眼睑。闭眼的目标回到皮肤上、睫毛之下，闭眼时不露薄壳。

## 胯关节 X 用膝环

`skeleton` 的 `hipJoint.x` 取静止膝环中心的 x，`rig_landmarks` 保留解剖地标。`UpperLeg`、`UpperLegHalf` 使用这个位置，使大腿从正面看近似竖直，屈髋时朝正前方。

骨骼的胯比股骨头地标窄，差值随身体变化，下蹲时两膝可能比真人靠得近。验证 `crouch`、`stride` 和分腿姿势时，检查腿过中线、左右腿互穿、正面小腿是否呈 V 形及腹股沟近景。

## 腰以下的权重拟合

默认开启。入口只有一个：`skin_weights` 最后调用 `sotaigen/rig/skeleton.py` 的 `fit_lower_body`，所以构建、`rigged`、导出、测试和脚本用的都是同一份权重。`skin_weights(..., fit_lower=False)` 给拟合前的权重，只用来对比。

**边界：** 只动躯干、大腿、小腿的皮肤。躯干长的 22% 高度以下全量，往上用 `smooth` 淡出，到腰线地标为 0；往下到膝踝中点淡出。淡出带里把拟合结果和原权重按比例混合，再用 `limit` 截断，所以连续。拟合只用躯干和腿的骨骼，不跨到对侧。样例姿势是 `sotaigen/rig/skeleton.py` 的 `FIT_EXAMPLES`，改检查姿势不会影响权重。

- 区外的顶点权重和拟合前逐项相同，函数自己检查，不符就报错。`tests/test_rig.py` 在全部身体上把关，也查归一、影响数和区域边界不新增接缝。
- 区域边界上相邻顶点的权重差几乎不变。
- 手臂和头颈类姿势一点没动：`armsDown`、`armRoll`、`wristRoll`、`armsUp`、`reach`、`elbowBend`、`headTurn`、`headNod`、`fist` 的顶点差为 0。动的只有 `crouch`、`stride`、`twist`。
- 弯腰、扭腰时腰部图上没有分界线。
- 确定性：分开进程强制重建两次，`weights.npz` 逐字节相同。

**依据：** 采用 SSDR 的权重步骤（Le 和 Deng，2012），固定骨骼，以 delta mush（Mancewicz 等，2014）生成的姿势目标求每个顶点的权重。固定样例姿势由 `FIT_EXAMPLES` 定义。

**验证：** 对当前身体检查下蹲、坐姿、跨步和髋外展。拟合会重新分配折痕中的压缩，塌陷数量不能单独表示观感；需定位面片并查看轮廓、明暗线及遮挡。拟合不提供接触保护。

**代价：**

- **构建：** 增加局部权重求解，按受影响顶点批量计算；当前耗时需随身体与运行环境记录。
- **运行时：** 只改权重，文件大小不变，默认导出需通过 `runtime-check`。VRM 同样只是权重，但没有实际导出验证。

## 局部绑定与修正

腹股沟使用腰以下权重拟合与[姿势雕塑](../parts/groin.md)，肩腋使用[姿势目标](../parts/shoulder-axilla.md)。姿势目标需由运行时驱动或烘入动画。

腕、踝按前臂和小腿长度的 17% 做额外权重扩散，使过渡带具有稳定的物理长度。手腕使用半转骨分担屈腕与滚转，见[四肢](../parts/limbs.md#屈肘-145-和屈腕-60)。

肩带联动比例 `SHOULDER_RHYTHM` 为 0.2，是静止手臂已抬起时的工程近似。修正与上臂扭转骨按真实摆动、扭转读取姿势，见[摆动加扭转](blend.md#摆动加扭转)。

## 垂臂的隐式场修正

`sotaigen/corrective/hang_field.py` 使用身体自身的体块隐式场，将放松垂臂时的前臂和手推回场外；方法参考隐式蒙皮（Vaillant 等，SIGGRAPH 2013），选择它是为了满足[生成速度目标](../ARCHITECTURE.md#1-目标与边界)。目标、键和驱动接口与 IPC 垂臂表一致，默认路径不读取 IPC 缓存。

身体侧与手臂侧分开计算，再在摆姿后的空间求接触修正；对称身体镜像，非对称身体分别求解。手指深陷大腿时沿身体场梯度退出，避免沿手指自身法线推而压塌指尖。它处理放松垂臂时的前臂和手接触，上臂与胸侧接触不在这一修正中。屈肘、扭臂、转手与同侧屈髋时，垂臂修正淡出。具体间隙和键由实现定义，`tests/test_hang_implicit.py` 检查各身体的键上与键间姿势。

新增目标会增加文件与运行时变形纹理成本；当前成本按[导出测量方法](export.md#大小和耗时)复测，不用旧目标数量或旧耗时代替。

## 真实动作、根位移和支撑脚

五段 CMU 录制从 120 Hz 取样为 60 Hz。根位移按腿长缩放，统一对齐首帧朝向，保留后续转身和腾空。在源足部轨迹上估计脚跟和前足的支撑区间，按目标体型的足底位置求髋、膝、踝旋转。普通播放器读取根平移和已烘焙的各骨旋转，评审用 10 Hz 抽取同一求解结果。水平地面上单脚和双脚支撑分别处理；源数据没有压力传感器或凳面接触标注。参考足滑约束的表述见 [Kovar 等的原始论文](https://graphics.cs.wisc.edu/Papers/2002/KSG02/cleanup.pdf)，原始录制与比例单位见[动作数据说明](../../motions/SOURCES.md)。

**步行脚踝。** 足底最低点的高度只能检出悬空和穿地；不约束时，跟、前掌同时支撑的那段两处足底标记会差出两厘米，摆腿时脚掌俯仰会在一帧内反转几十度。现按每只脚的双点支撑区间估计足骨、趾骨各自的静止偏差，保留动捕中的水平朝向。双点支撑时让脚掌放平，单点支撑和腾空时逐渐撤去约束。对远端采样的短时反转用居中旋转滤波抑制。支撑关键帧的最低点误差低于 0.01 mm，普通播放器在相邻关键帧之间插值时，最低点偏差一毫米多。复现：`clips.py contacts <身体> --clip walk` 打印约束前后的支撑脚高度和滑移，`clips.py glb` 出可在播放器里看的 GLB。
