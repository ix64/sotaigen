# 贴合与 UV

模板贴到隐式曲面、接缝上限和 UV。手脚接缝和关节边环见[四肢](../parts/limbs.md)，腰腹过渡的贴合见[躯干](../parts/torso.md)。

**还没解决：**

- 腋下 UV 拉伸需要在当前形体上复测，见“已知缺陷”和 `scripts/uv_check.py`。
- 腋下的参数连续性尚需复核；见[连续性检查](editor.md#流水线自己会跳)。
- 支持身高范围外的贴合、绑定、UV 和导出未完整验证，见[接缝规则](#接缝规则sotaigenparamsrulespy)。

## 现状

`tests/test_wrap.py` 检查投影翻转、越中线、脚底着地及接缝。接缝偏差上限按肢体末端半径比例计算，见[接缝上限](#接缝上限)。所有身体共用 `sotaigen/data/template/uv.npz`；重新展开后须检查 UV，不以 Blender 命令完成代替验证。

肩腋贴合使用前襞、腋底、后襞三个材料地标，替代单一交界最低点。贴合保持已有顶点顺序，新增的肩腋环按[加环流程](../parts/shoulder-axilla.md#腋下加环)处理并同步 UV。实现与对照见[肩腋与胸侧](../parts/shoulder-axilla.md#形体与姿势修正)。

**诊断脚本：**

| 脚本 | 用途 |
|---|---|
| `scripts/locate.py` | 翻转和曲面误差出现在哪个分段、什么高度 |
| `scripts/raw_info.py` | 模板自身的包围盒和关节位置 |
| `scripts/joint_loops.py` | 各关节的边环数、间距，弯曲外侧的折角 |

## 已知缺陷

| 名称 | 问题 | 影响 |
|---|---|---|
| UV 拉伸 | 腋下受压面可能有较大局部 UV 拉伸，严重程度需按当前身体复测 | 贴图在腋窝局部被拉成条，一般看不到 |

## 接缝上限

**规则：** 接缝偏差不超过肢体末端半径的一定比例，手 0.65、脚 0.52（`sotaigen.form.wrap.SEAM_MISS_SHARE`）。半径是接缝环到环心的平均距离，从贴合结果量（`sotaigen.form.wrap.seam_radius`）。折角上限无量纲，手 35°、脚 16°。`wrap.json` 里偏差按毫米记录。

**为什么选末端截面，不选身高：** 偏差是两个中心对齐的截面之差，一个是肢体末端，一个是缩放后的手或脚，所以它跟着截面走：偏差最大的是矮小的身体，不是高大的。按身高、躯干长或手脚长定的上限，要么对矮身体放松，要么在大身体的粗肢体上误报；按末端半径定的上限对同一身体放大缩小都给同样的判断，而手小到接不上前臂、踝粗配小脚这些看图一眼能看出的问题都超限。参数给的半径和实测差得不少（手腕很细时实测约多 3–4 mm），所以用实测。

## 绝对毫米的常量

贴合包含固定毫米步长，不是严格的尺度不变映射：`march_many` 的步长与上限、梯度差分步长、颈轴与颈环采样均按毫米定义。模板坐标的常量只作用于固定模板，不随身体缩放。

隐式场的中线圆滑宽度为 10 mm，腕、踝、颈端面裁切宽度为 4 mm；腰胯校准测宽使用横向 0.5 mm 步长。缩放复测应将身体等比放大再缩回，比较顶点、接缝比例和目标实测量，分别定位场与贴合的误差。

这些数值是当前算法的工程尺度，修改会改变生成结果，需重新检查全部典型及测试身体。

## 接缝规则（`sotaigen/params/rules.py`）

现行式子与阈值见[参数与预设](params.md#规格上的规则)。接缝比例和折角均为无量纲量，规则不另乘身高因子；整体缩放误差仍需按上节单独复核。

**身高：** 支持范围仍由 `STATURE_RANGE` 限定为 1000–1800 mm，范围外的贴合、绑定、UV 和导出尚未完整验证。

## 颈部的排

**做法：** `seat_neck_ring` 定位颈环后，将每个 `neck_columns` 列摆到颈环与躯干端点之间，再沿曲面按弧长等分、投回曲面，共 3 遍（`NECK_PASSES`）。这样同时约束横向滑动和排距，避免喇叭口上的拉普拉斯松弛把顶点挤向细的一端。

只处理颈部 9 排 × 36 个顶点；场、目标颈围和求解结果不变。颈根与躯干相接处的排距仍不连续，后外侧面片的周向边也较长，需要单独检查。

`wrap.json` 的 `flippedFaces`、`crossedMidline`、`brokenAt` 读取颈环定位后的网格；`surfaceErrorMm`、`edgeChangeFromWarp`、`shortestEdgeMm`、`cornerAngleDeg` 读取这一步之前的贴合，不能拿它们代替颈部检查。

头颈 UV 在 12 个典型身体的平均形状上展开，命令见 [PROVENANCE](../../template/PROVENANCE.md)。图集与排布必须匹配；`extract_uv.py` 的 `pack_tightest` 从 `PACKINGS` 中选择覆盖率最高的排法。形体或排布变化后运行 `tests/test_uv.py` 与分区拉伸检查，并重新验证颈部动作及接触缓存。

## 批量计算

射线与颈环按批调用隐式场，四边面法线和角度用 NumPy 数组计算。主要成本仍在投影与隐式场求值，性能需按当前身体、依赖和运行环境测量。

编辑器采用松手后精确生成；产品目标见 [DECISIONS](../DECISIONS.md#产品与范围)。

## UV

**源文件：** `GEO-body_female_stylized` 有可用的 UV，一层 `UVMap`，人工展开，55 个岛（模板部分），没有翻转，左右不共用。问题是它铺在多个 UDIM 格子上（身体、手、脚各一格），手脚的密度远高于身体。glTF 和 VRM 用不了 UDIM，所以不能照搬。

**方案：** 单张 0–1 图集。

- **身体：** 保留源文件的岛，只统一密度再重新排布。
- **头和颈：** 能统一。头是函数生成的，没有 UV，所以把颈部和头作为一个岛重新展开（Blender 的 Minimum Stretch），只沿后脑到后颈中线切一刀。贴图可以连续穿过颈环，脸在岛的中央，头顶在切口尽头。
- **密度：** 以 12 个典型身体的平均形状为基准统一，头 1.5 倍、手 1.25 倍（`extract_uv.py` 的 `DENSITY`）。头的份额是为五官留的。
- **生成：** `template/extract_uv.py` 在 Blender 里运行，产物是 `sotaigen/data/template/uv.npz`（约 0.1 MB，16 位定点，按面角存）。`verts`、`faces` 及其顺序不变。肘、膝加的环在源 UV 上插值，见 `template/PROVENANCE.md`。
- **读取：** `sotaigen.uv.load_uv(faces)` 按面角给出坐标，拓扑对不上时报错；`sotaigen.uv.export_fields(faces)` 给出导出约定的 `uvs`、`faceUvs`（V 朝下）。
- **限制：** 头部拓扑变了要重新运行 `extract_uv.py`，否则 `load_uv` 报错。

**指标（全部身体，`tests/test_uv.py` 的常量；`scripts/uv_check.py` 出逐身体的读数）：**

| 指标 | 上限 |
|---|---|
| 重叠的三角形对 | 0 |
| 翻转、零面积 | 0 |
| L2 拉伸（Sander，1 是无拉伸） | 1.15（`L2_STRETCH`） |
| 各向异性 p95（圆变成椭圆的长短轴比，按面积加权） | 2.2（`ANISOTROPY_P95`） |
| 贴图密度相对均值 p5／p95 | 0.6／1.8（`DENSITY_P5`、`DENSITY_P95`） |

密度的宽带是有意的（头和手更密）。密度上下限只查头以下的皮肤：头的区块在图集里占固定份额，身体越大头越显得密，大身体的头会到均值的两倍以上。脚趾有几个极小的面各向异性约 20，来自模板自身，所有身体相同。导出时接缝处的顶点要复制。

## 法线和体块的证据

用同一相机和光照比较隐式场与网格，区分体块方向造成的明暗变化和网格采样的折线。诊断方法与部位线索统一见[形体生成](form.md#toon-线索的原因)。场法线不能代替导出网格及动作后的法线检查。
