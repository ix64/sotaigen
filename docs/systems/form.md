# 形体生成

隐式场搭大形的总体情况。按部位的结论在 [parts/](../parts/)。

## 现状

生成器由关节地标和体块构造曲面。关节地标是模型的骨性参照，体块按下面的结论搭；比例由参数决定（[参数与预设](params.md)）。

肩腋形体：隐式场保留腋底凹面，并为抬高腰线的邻接区域提供平滑避让；解剖依据、模型简化与动作证据见[肩腋与胸侧](../parts/shoulder-axilla.md#解剖依据与结构复核)。

**诊断脚本：**

| 脚本 | 用途 |
|---|---|
| `scripts/check_targets.py` | 逐个身体对比参数要求和实测的腰、胯宽，加贴合摘要 |
| `scripts/silhouette.py` | 正、背、侧轮廓的极值，用来找鼓包 |
| `scripts/terminator.py` | 同一相机和光向下，分别从隐式场、贴合网格、摆姿势后的网格出明暗交界线，并画网格法线与场法线的夹角，用来判断一处转折来自哪一层 |

## 已知缺陷

| 位置 | 现象 | 判断 |
|---|---|---|
| 肘外侧 | 伸直时轮廓仍有一个小折角 | 骨链弯曲集中在关节球的短弧上，需结合骨链角度、体块与网格检查 |
| 腿根 | 两腿缝隙顶端还有一小块阴影 | 场上很小，到网格才变大：这里是网格法线和场法线差得最多的地方，属于网格采样 |
| 后腰到臀部 | 交界线在暗面里留一块亮区 | 见“toon 线索的原因”，这是臀上部的真实朝向，不是缺陷，只是边缘的折线属于网格 |

**颈肩侧面的明暗线。** 用同一台侧视正交相机、灯光和 toon 阈值，分别渲染实际网格（导出时的颈部法线）和隐式体块（沿视线求交、取场梯度），只比较两边都有可见界线、且面属模板颈部的行。大形在体块上就是缓弯，所以保留。网格上局部有一两毫米的向前折返，场上同段仍向后走，这是模板取样和表面法线的问题，没有定位到单一肌肉。

## 局部控制

系统设计参考人体骨骼、肌肉和软组织研究，参数支持范围由通用模板的贴合和动作试验确定。

**下肢设计先确定骨段与肌群。** Handsfield 等用 MRI 测量 24 名受试者的 35 块下肢肌肉，分别记录肌肉长度、体积及其与骨尺寸的关系；Rajagopal 等的步态模型分别表示骨几何、关节运动和肌腱肌肉单元。据此把两类试验分开：调腿段比例时检查骨性参照和关节运动；调大腿前后轮廓时固定股骨，观察沿骨段的多个截面。模板环中心、软组织位移系数以及能通过贴合测试的区间都按本模型的工程量记录。[下肢肌肉 MRI 原始研究](https://pubmed.ncbi.nlm.nih.gov/24368144/) · [全身肌骨步态模型及验证](https://pmc.ncbi.nlm.nih.gov/articles/PMC5507211/)

**脚踝的诊断。** 接缝需联合检查脚长、踝围与踝高，不能把一次单参数试验的通过区间当作全部组合的支持范围。

| 部位 | 控制 | 结果与边界 |
|---|---|---|
| 脚踝 | `ankleHeight` 在固定脚长时调节赤脚踝高。长脚、细踝的组合允许接缝环在水平方向分担修正。 | 长脚细踝的折角回到上限之内，范围两端都通过着地、折角、接缝偏差和足面朝向检查。鞋内贴合仍需单独验证，赤脚的几何检查不能保证穿鞋无穿插。[量法与支持范围](wrap-uv.md) |
| 膝与裆 | `kneeHeight` 在固定裆高的条件下分配大腿和小腿长度（内部控制量 `kneeHeightRatio`）。 | 骨架从成品膝环取关节位置。跨步没有塌面，下蹲仍有折痕塌面。 |
| 胸型 | 乳房是胸壁上的厚度场，六项毫米量和比例（`breast*`），见[胸部](../parts/chest.md) | 典型身体和测试身体的贴合、绑定无翻面、无越中线 |
| 大腿前后轮廓 | `thighFrontShift` 沿固定股骨改变软组织外形，默认值为 0。 | 交叉膝高和大腿轮廓取值时，中段截面围度的端间差不超过 1 mm。该控制只描述表面轮廓，不能据此推算股四头肌或腘绳肌体积。 |

`breast*` 和 `thighFrontShift` 是可选项，不写时取 `sotaigen/params/spec.py` 的缺省值。各项的量法：

| 核查内容 | 记录 |
|---|---|
| 同一胸前地标和下缘随姿势的位置，水平围、侧绕路径与缺测的区别 | [胸型量法](../parts/chest.md#固定材料地标与避臂量体) |
| 固定髋轴后各段大腿的厚度，以及允许的加粗范围 | [分段轮廓](../parts/hip-thigh.md#固定股骨后的分段轮廓与内侧覆盖) · [跨风格边界](../parts/hip-thigh.md#固定髋轴加粗的跨风格边界) |
| 窄腰和窄胯在曲面上能否达到，如何阻止同侧体块越过中线 | [腰、骨盆与大腿根](../parts/hip-thigh.md#腰骨盆与大腿根的可达宽度) |
| 身高缩放时中线、裁切和腰胯测宽步长各自造成的偏差 | [缩放复测](wrap-uv.md#绝对毫米的常量) |
| 同一相机与光照下，颈肩明暗线的哪些转折已存在于体块 | [颈肩侧面对照](#已知缺陷) |

## 造型参考与解剖依据

Bridgman、Bammes、Hampton 和 Mattesi 的体块、骨点、肌群简化及轮廓错峰方法用于组织大形。比例由参数定义；单块肌肉的起止点、附着和动态关系按对应部位及动作卡的研究核对。是否表现某个表面细节取决于目标风格与网格分辨率，不能把早期简化方案写成不再研究解剖的限制。

## toon 线索的原因

用 `scripts/terminator.py` 在同一相机与光照下比较隐式场和网格，区分大形与采样误差。

| 位置 | 来源 | 当前处理 |
|---|---|---|
| 后腰到臀部 | 臀上部朝上受光；网格采样与后腰极点影响边缘 | 保留体块亮区，检查边缘折线 |
| 胸侧 | 胸部边缘 | 检查胸壁、胸肌与乳房厚度场的连接，见[胸部](../parts/chest.md) |
| 躯干侧面 | 胸廓上部朝上 | 背阔肌支撑到腋下，局部折线需结合网格检查 |
| 腿根 | 切槽顶端的场与网格法线差异 | 检查顶端局部阴影与采样密度 |

`Ellipsoid.taper` 在截断处使用切线延续，避免骨盆与胸廓融合区出现水平斜率跳变。
