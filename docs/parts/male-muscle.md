# 男性肩胸背肌肉

**现状：** 四项可选参数 `pectoralThickness`、`deltoidThickness`、`trapeziusThickness`、`latissimusThickness`（`sotaigen/params/spec.py`，层 `muscle`），单位 mm，是加在对应体块上的量，不是成品表面的实测。典型身体的取值以 `sotaigen/data/bodies/male/typical/` 为准，比例依据见[预设](../systems/presets.md#男性的三个年长身体)。缺省时形状不变。它们和胸部一样不进中性测量面（`sotaigen/form/measures.py` 的 `LOCAL`），所以求解不会缩小胸廓来抵消胸肌。

**两个性别都有：** 四块肌肉男女都有，只差在量，所以这四项也对女性开放（[按性别](../systems/params.md#按性别)）。乳房是厚度场，坐在胸板上，胸板的下缘在乳房下面缓降到下皱襞（[女性胸肌](chest.md#女性胸肌没有可见下缘)）。有乳房的身体上胸肌最多 `0.0225 T`（`sotaigen/params/rules.py` 的 `pectoral_under_breast_thin`），更厚的没有看过图。

**编辑器：** 四项是“肩胸”组“肌肉”下的四个滑块，两个性别都显示，缺省 0。有乳房的女性身体上，胸肌超过 `0.0225 T` 的一段标为不能生成（[参数](../systems/params.md#按性别)）。

**抬臂：** 胸板不只随蒙皮走。`sotaigen/corrective/pectoral.py` 在肩部修正的每个采样姿势上，把胸板外侧的厚度跟着肱骨上的止点往上、往外带，下缘从胸骨旁斜到前腋襞，被带走的部分变平（[动态卡](../motion/shoulder-chest.toml) 的 `pectoral-follow`）。增量加在肩部修正自己的目标上，目标名和驱动不变，网页和 GLB 不用改；在 `Correctives.production` 取得肩部目标后叠加。接触表的缓存不能代替叠加后成品的接触检查。

**胸前的斑块：** 胸板的每段斜坡至少跨模板胸前的两条边，胸骨中线留四成厚度，所以胸前没有沿网格的块状明暗，胸骨两侧没有 V 形，见[胸板的斜坡和网格](#胸板的斜坡和网格)。

**还没解决：** 较厚胸肌的下缘转角、斜方肌与后颈的连接需要看图复核。现行范围是工程支持范围，不代表全域观感已验收；调整范围须重新检查静止轮廓、抬臂和接触。

## 控制的分工

肩宽、胸廓和上臂围控制整体尺寸；这四项分别控制胸肌、三角肌、斜方肌和背阔肌的体量，避免只能靠放大整个肩胸区表达肌肉。

## 四项肌肉（`sotaigen/form/anatomy.py`、`sotaigen/form/pectoral.py`）

| 参数 | 体块 | 做法 |
|---|---|---|
| `pectoralThickness` | 胸板 `sotaigen/form/pectoral.py` 的 `PectoralPlate` | 不是体块，是读场时把胸前表面向前推的厚度分布：锁骨下为零，胸骨中线留四成，在中线外 0.07 T 内长满，到下缘增到参数值，下缘以下 0.05 T 内归零，外端在腋前 0.07 T 内归零；下缘从胸骨旁 0.77 T 向腋前升 0.06 T（同一文件的 `BORDER`、`BORDER_RISE`、`DROP`、`GROOVE_WIDTH`、`GROOVE_FLOOR`、`OUTER_FADE`）。参数就是下缘处的厚度 |
| `deltoidThickness` | 三角肌帽 | 半径加大，中心向外移，只向外长，不伸进腋窝 |
| `trapeziusThickness` | 斜方肌 | 加厚并抬高颈侧端，颈到肩的线更陡 |
| `latissimusThickness` | 背阔肌 | 上端向外、向后展开并加粗 |

胸肌不用融进胸部的体块：任何形状的体块经同一个融合宽度后，上下两缘一起被磨圆，侧面总是近乎对称的钟形。所以改成坐标偏移，和臀形、腹前弧同一种做法，厚度分布可以直接写成楔形。

包装的顺序由里向外是胸板、乳房厚度场（[胸部](chest.md#三层结构)）、臀形。臀形放最外层，因为贴合先贴到它包着的场再搬过去；它读的是它包着的场，并把 `clips` 转过去，所以里面的两层不会丢。两层厚度相加，乳房坐在胸板上。

## 胸板的斜坡和网格

**来源。** 胸前网格法线和场法线的夹角随胸肌量增大，所以不规则的明暗斑块来自胸板，不是几个体块叠加。场本身是平顺的：场的着色上是一道整齐的下缘和胸骨两侧两道竖直的沟壁（`scripts/terminator.py` 的 field 一栏也是这样）。模板胸前的边长约 0.027 T，一段只跨一条边的陡斜坡被斜穿它的边环采成沿边环的块状明暗。锁骨、斜方肌、三角肌一带胸肌 0 时也有偏差，男女都有，只在锁骨附近。

**做法。** 每段斜坡至少跨两条边：胸骨沟从中线起在 0.07 T 内长满，下缘以下 0.05 T 内归零，外端在 0.07 T 内归零。胸骨沟和胸板一样深时，往下越深，侧光下胸骨两侧一亮一暗，是一个 V；所以胸骨中线留四成厚度（`GROOVE_FLOOR`），沟变浅，两侧下缘在中线连成一条。

**依据。** 胸大肌的胸肋部附着在胸骨前面和肋软骨上，最常见的是第 2–6 肋，胸肋部起点宽 133–215 mm；锁骨部和胸肋部之间通常只有一道浅裂（[Haładaj 等 2019](https://doi.org/10.1155/2019/6212039)，80 侧尸体，经 PubMed 读全文）。起点沿胸骨连续，所以胸骨中线的浅沟是真的，但它是连续的一条，不该在网格上断成块。锁骨部薄，平均厚 5 mm（2–7 mm，[Williams 等 2000](https://doi.org/10.2106/00004623-200012000-00007)，10 侧尸体，只读了摘要），锁骨下薄、往下变厚的楔形有依据。下缘在体表是看得见的界线：26 名水球运动员的乳头平均在“胸大肌下缘阴影”上方 2.5 cm（[Tanini 与 Lo Russo 2018](https://doi.org/10.1007/s00266-018-1131-0)，只读了摘要）；男性胸部整形把切口放在“胸大肌下沟”上，当作胸部两个美学单元的分界（[de Faria 与 Sterodimas 2010](https://doi.org/10.1007/s00266-010-9593-8)，只读了摘要）。这些研究没有量沟和下缘有多宽、沟有多深，0.05–0.07 T 是网格分辨率定的工程值，中线的四成是看图定的。

**还剩的。**

- 胸骨沟是一道宽而浅的沟。要窄而清楚的沟，模板胸前要更密，或者让沟和下缘顺着模板的边环走。
- 夹角仍比不加胸肌时大：12 mm 的落差在两条边内走完，网格只能画出一个软的下缘。
- smoothstep 在斜坡两端曲率跳变，场的着色上可能出现淡的矩形边，需检查成品网格的明暗线。
- 锁骨一带的小起伏男女都有，胸肌 0 时也在，来自锁骨体块的窄融合（`sotaigen/form/anatomy.py` 的 `clavicle_masses`），这里没动。

## 验证

在正面、侧面和背面检查各肌群的轮廓与连接，再检查抬臂时的胸板随动。范围定义在 `sotaigen/params/spec.py`，组合限制在 `sotaigen/params/rules.py`。胸板须向外传递 `clips`，保持贴合和头部去裁切流程。

复现：`uv run sotaigen-dev build male-balanced`，`uv run sotaigen-dev review sheet male-balanced female-balanced --pose rest --view front,side,threequarter,back --look clay`。
