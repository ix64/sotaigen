# 四肢

大小腿和前臂的线条、膝环、足部结构、手脚接缝、关节边环、肘尖和手势。肘部的现象取舍写在[肘部卡](../motion/elbow.toml)。

**还没解决的问题：**

- 屈肘 120° 起前臂穿进上臂（尚无处理两段肢体相压的接触修正），屈肘的接触修正没有原型，见[屈肘 145° 和屈腕 60°](#屈肘-145-和屈腕-60)。
- 踝的权重过渡带按跳数扩散、不按毫米，`crouch` 的踝部还有一道软的隆起，没有验证是不是来自权重。
- 脚趾下缘的小锯齿、踝环前方的台阶；足弓高度是固定形状，不是参数。
- 拾取动画的 three.js 回读是在拇指重新拟合之前做的，之后没有重跑；两段手工编排的样片没有覆盖任意位置和尺寸的道具。
- 膝高比例、踝高、手脚接缝和足部结构需在当前身体上完整复测。

## 独立分配大腿和小腿长度

Aitken 用 1,077 条成人下肢的站立位全长 X 光片分别量股骨和胫骨。股骨从股骨头顶部量到股骨内侧髁中心，胫骨从内侧平台中心量到胫骨远端关节面中心。样本的股骨长与胫骨长之比为 1.16–1.39。上下腿段的相对长度存在个体差异，值得单独控制。模型用裆到地面的距离包含足部，也绕开了股骨头，因此不能把这组骨长比直接换算成膝高与裆高之比。[Aitken，2021，成人下肢站立位影像](https://doi.org/10.3390/osteology1020009)

负重屈膝的双平面 X 光追踪表明，在 20 名健康受试者中，股骨后髁中心连线比经上髁轴更接近实测屈伸轴。另有 10 人的被动屈伸超声实验发现，改变膝角与改变踝角对腓肠肌内侧头肌束和肌腱伸长的作用不同。模板膝环是体表截面，骨架只取环中心作铰接点。跨步和下蹲用来复查网格屈伸时膝窝和小腿的形变，目前的蒙皮没有追踪股骨髁或跨关节肌腱的行程。[负重膝屈伸轴研究，2015](https://doi.org/10.1371/journal.pone.0128877) · [De Monte 等，2006，腓肠肌超声实验](https://pubmed.ncbi.nlm.nih.gov/16309922/)

参数 `kneeHeight` 的内部控制量 `kneeHeightRatio` 范围 0.54–0.66（`sotaigen/params/spec.py`），乘以赤脚裆地标高度得到膝地标高度。身高、裆部、足长和踝高的地标仍由各自的输入决定。贴合后从成品膝环取骨骼转轴，角色量体时也量同一圈。

改膝高比例时，裆底、踝环高度和成品脚长几乎不动，腿骨转轴都在成品膝环中心；`crouch` 和 `stride` 腿不越中线，`stride` 没有塌陷面，`crouch` 的塌陷面随体型和腿段比例变化。侧面同尺度对照里，提升膝位后，屈膝时大腿前伸距离变短，小腿到足底的距离变长。

**身高缩放。** 隐式场的中线平滑宽度、端面裁切宽度和腰胯校准测宽步长含固定毫米常量，因此缩放不严格保持同一形状。场与成品网格需分别复测，见[绝对毫米的常量](../systems/wrap-uv.md#绝对毫米的常量)。

## 膝环

骨架从成品膝环中心取关节位置。股骨沿半胯正中布置，校准不移动胯、膝地标；截面中心与骨性参照仍可能因软组织与融合存在差异。检查膝环是否过中线、下蹲时两膝和小腿的朝向。

## 肘、膝的转折和小腿、前臂的线条

**关节处不能让两段骨头宽融合。** 平滑融合在两个面相等处向外鼓 `k/4`，这个位置恰好是两段骨头的共同端球，于是在最该细的地方鼓出一圈窄环。网格的边环跟不上这圈窄环，灰模上是一条横带，toon 里是一个折角。所以股骨与胫骨、上臂与前臂各自组成骨链（紧融合 `0.012 T`），肌肉另成一组再融合。

**线条来自直线和曲线相对，不来自对称的鼓包：**

- 膝是整条腿最窄的转折，宽度和深度都比从柔软肢体继承的半径小（`KNEE_SECTION`）。
- 胫骨前缘直，小腿肚的曲线都在后面。膝前没有髌骨浮雕。
- 前臂靠近肘是圆的，向腕部变扁（两根骨头并排）。肘的半径偏向上臂的尺寸，只取一部分腕的尺寸。
- 前臂相对上臂外偏 4°、前倾约 7°。外偏是真人提携角的方向（常见 5–15°），画得小，因为角度全集中在一处，再大就是折线。内收时方向反了，垂臂时手会撞进髋部（[垂臂卡](../motion/arm-hang.toml)）。

## 肢体两侧要不要不对称

要，但只在前臂和小腿肚，幅度要小。

- **前臂：** 留。外侧伸肌的峰靠近肘，内侧屈肌的峰偏下。肘外侧的折角被吸收进前臂的外轮廓，比单个肌腹耐看。
- **小腿肚：** 留，外侧头比内侧头高，偏移只有小腿半径的约 13%。改变错峰幅度时需检查膝下外侧是否出现台阶。
- **大腿内外侧：** 内收肌和外侧体块本来就错开，保留原有位置。

## 关节处的边环

**肘、膝加密：** 肘、膝两侧各加 2 个环，每个关节 4 个，左右合计 400 个顶点。做法和约定见 [ARCHITECTURE](../ARCHITECTURE.md#34-数据约定)的“模板”、[坐标与拓扑](../reference/coordinates-topology.md)和 `template/PROVENANCE.md`。

用 `scripts/joint_loops.py` 量关节一个肢体半径内的环数，以及弯曲外侧相邻面的夹角。屈侧的压缩另按动态卡区分预期折痕，不能仅凭数量判断。

权重在基础网格上计算，再沿边插值到新顶点（`coarse`、`prolonged`），使按边数扩散的过渡带保持原有物理长度。手指用细分曲面改善截面，肩腋环见[肩腋](shoulder-axilla.md#腋下加环)。

## 肘尖

现象和取舍见肘部卡。半转骨让皮肤绕轴走圆弧，点到轴的距离不变，够不到两段肢体背线相交的转角，所以肘后是倒角，还向内缩。解剖上鹰嘴属于尺骨，伸直时略高于两髁连线，因此 `seat_elbow_tip` 让背侧皮肤跟随前臂到关节上方 0.8 个肘半径，再用 1 个肘半径的过渡带交给上臂，方位角 70–150° 之间逐渐生效，屈侧不动。只改权重，运行时和文件结构都不变，静止姿势不移动。

肘背使用一轮平滑以保留转角；深屈时肘尖与侧面连接处的细线仍需检查。

**没有解决：** 前臂和上臂的相压。短头身的身体从 90°、其余从 120° 起前臂穿进上臂，现有权重方案没有处理两段肢体相压。

## 屈肘 145° 和屈腕 60°

12 个典型身体上屈肘 145°、屈腕 60° 的情况，复现用 `uv run scripts/upper_body_study.py poses` 和 `sheet`（`--focus elbow`、`--focus wrist`）。肩腋部分和工具的用法见[肩腋的诊断](shoulder-axilla.md#上半身目标角度的诊断)。

深屈肘需检查前臂与上臂穿插、正面明暗斑块、背面双层轮廓及肘窝尖缝；塌面位置按[肘卡](../motion/elbow.toml)判读。屈腕检查腕背圆弧和掌侧折痕。读数取本次报告，不沿用旧身体的计数。

**屈肘接触：** 尚未实现接触修正，深屈时的前臂／上臂相压仍是限制。

**屈腕的做法：** 两处改动。

- **半转骨 `HandHalf`：** 取手一半的摆动，从腕环中心转，再取手真实扭转的 0.875（`HALF_ROLLS`，在前臂最后一根扭转骨的 0.75 和手的 1 之间）。摆动和滚转共同分配腕部形变；回归需覆盖屈腕与滚转组合，检查掌侧压扁与箍痕。
- **只平滑腕背的权重（`round_wrist_back`）：** 按跳数扩散的权重在手的接缝处有台阶，那里排距只有 3 mm，混合比却跳一大步，外轮廓就在这几排上转弯。在腕的过渡带里按毫米再平滑一次（`smooth_over_length`，半径 0.15 手长），只作用在手背一侧（从掌侧量方位角，70° 没有、150° 起全部），掌侧的折痕不动。

当前腕部是同一转心分两步，配合腕背长过渡，目标为腕背圆弧与掌侧横褶。检查屈腕、伸腕及滚转组合；掌侧预期折痕中的压扁面按[腕卡](../motion/wrist.toml)判读。

## 手脚接缝

接缝需要同时保持环的位置、手脚的实际挂接中心及跨缝位移的连续性。剩余踝部隆起需结合权重检查；左右手因姿势互穿造成的交线不属于接缝问题。

**做法：** 环不参与切向松弛，只投影。手从环的实际中心出发；脚只取水平位置，高度不变，否则离地。修正量用双调和方程填充，两侧各固定 3 排，值和斜率都连续。填充范围是接缝 70 mm（模板尺度）以内，手指和脚底不受影响。矩阵只取决于模板，不需要新依赖，运行成本需按当前环境测量。

剩下的偏差是截面粗细和形状的差别（缩放后的手腕比前臂末端细），由修正量在 40 mm 内平滑吸收，这也让手掌根部比模板略宽。折角写在 `wrap.json` 的 `handSeamCreaseDeg`、`footSeamCreaseDeg`，偏差写在 `handSeamMissMm`、`footSeamMissMm`，都由 `tests/test_wrap.py` 把关，限度见[规格上的规则](../systems/params.md#规格上的规则)。

腕部近景有一处小的亮斑（手背靠近手腕），来自模板自己的腕部形状。

**极小缩放下的手指：** 手整体缩放，拓扑沿用模板。小身体的全身图里，手指可能只有几个像素宽，描边会影响指缝的可读性；这与几何穿插须分开判断。手势的接触、自交和成品三角形检查见下文[手部](#手部)。

### 长脚的踝环与踝高

在 8 名健康受试者的立体 X 光测量中，胫距关节转轴经过内外踝尖连线中点附近，轴向随姿势及个体变化。模型用一个赤脚离地高度定位踝地标，用皮肤网格上一圈顶点连接小腿与足体。量体时应分别记录地标和成品接缝环中心，两者都无法标出内外踝尖的各自位置。[Lundberg 等，1989，活体踝关节转轴](https://pubmed.ncbi.nlm.nih.gov/2915016/)

Teng 等在 10 名健康成人步行时同步追踪跟骨和测力板，测得跟垫在触地、承重、卸载过程中的压缩。跟底皮肤到地面的接触与骨性踝高是两项不同的测量。贴合时单独保留足底接触、水平脚长和远端厚度，属于静态网格近似。下述踝高支持区间、16° 接缝折角和 0.52 偏差比都是模板工程验收值。[Teng 等，2022，步态中跟垫的压缩](https://doi.org/10.1186/s12891-022-05197-w)

参数 `ankleHeight` 是赤脚时踝地标离地高度，必须在脚长的 0.24–0.55 倍之间（`sotaigen/params/rules.py` 的 `ankle_low_foot`、`ankle_high_foot`，见[参数与预设](../systems/params.md#规格上的规则)）。贴合保留脚的水平尺度；模板踝高以下 15% 的足底和趾部维持原厚度，15–35% 平滑过渡，以上的足背和脚跟共同承担高度变化。在允许的最低踝高上，垂向映射仍严格递增。

长脚接上较细的小腿时，如果整个踝环都锁在投影曲面上，接缝的转折会集中到第一排足面。用原方法量出的角度到 14° 时开始让踝环分担水平修正，到 18° 完全采用新的双调和解；两者之间连续过渡。环的 Z、上一排小腿和远端足形保持固定。偏差分子取成品环到同一套足部缩放及踝高变换所放置的未接合环的最大距离，分母取成品环的平均半径。

这样长脚细踝和低踝上的折角都在限度内，双脚及接缝的三角面都保持模板朝向。低踝下足背更平，脚后跟随之降低。复现用 `uv run sotaigen-dev test tests/test_wrap.py -k a_long_foot`。

## 长脚和细踝

长脚过得了接缝的限度：脚变长时偏差反而变小、折角变大，但都在限度内。拦住长脚配细踝的是脚踝下限（`sotaigen/params/rules.py` 的 `ankle_thin_foot`，踝围至少 0.75 脚长），它预防的是脚的折角：越过它的随机身体里有一部分脚折角超过 16°。

## 足部结构

**问题。** 脚不走隐式曲面，用模板网格整体缩放。模板的脚底几乎是平的，内侧三分之一的足底最高只离地 5.0% 脚长，外缘还悬空 1.2–1.7%，足背是一条直坡。

**做法。** `sotaigen/form/foot.py` 在模板坐标里做局部位移，都以脚长为单位，所以随体型缩放。脚长、最低点和踝环不动，后面的就位和接缝修正不用改。三角化后的拓扑和 UV 不变。

| 结构 | 模型的简化 | 依据 |
|---|---|---|
| 内侧纵弓 | 第一跖骨头后方到跟垫前缘抬起，舟骨下方最高，内壁向内收；外侧带贴地 | Cavanagh 与 Rodgers 的足弓指数（足印中段面积比）只用来判断足印有没有收腰 |
| 横弓 | 跖骨头后方中部浅抬 | 只按解剖关系，没有取实测值 |
| 跟骨 | 足跟后下缘向上收圆 | 只按解剖关系，没有取实测值 |
| 足背 | 足长 50% 附近压低 | Williams 与 McClay 的足弓高度指数（足长 50% 处足背高 ÷ 截断足长） |
| 舟骨粗隆、内外踝、跟腱两侧 | 沿 X 的局部隆起和凹陷，内踝比外踝高且靠前 | 只按解剖关系，幅度按观感取 |

**测量边界。** 足弓高度按观感取，没有文献目标值。足弓高度指数需从模型实测足背高与截断足长，不能用估算的截断足长宣称落入人群区间。网格足印的中段面积比对接地阈值和足跟收圆敏感，只作诊断。

**验证范围。** 贴合、UV 和接触测试覆盖全部身体。足弓只在内侧看得到，常规的 `side` 视角看的是外侧，要用 `uv run scripts/foot_study.py`。

**还没改。** 见文件开头。

来源：[Williams 与 McClay 2000](https://braceworks.ca/wp-content/uploads/2015/10/PHYS-THER-2000-Williams-864-71.pdf) · [足弓高度指数的量法](https://pmc.ncbi.nlm.nih.gov/articles/PMC7068515/table/ijerph-17-01274-t001) · [足弓指数的定义与样本分布](https://pmc.ncbi.nlm.nih.gov/articles/PMC3388464)

## 站距的形体做法

站距通过导出时旋转大腿调整，见[换静止姿势](../systems/blend.md#换静止姿势)，当前没有形体站距参数。改变静止姿势后需复核肩腋、腹股沟修正与接触，以及下蹲时膝足朝向。大腿外展也可能改变实测最大胯宽，不能把输入胯宽直接当成换姿势后的读数。

## 手部

检查姿势 `padPinch` 驱动第一掌骨对掌，使拇指和食指的指腹相向。`cylinderGrip` 将五指放在同一参考圆柱两侧，半径取腕至中指掌指关节长度的 0.258 倍。两者可在编辑器和导出 GLB 的姿势列表中选择。看图：`uv run sotaigen-dev review sheet female-balanced male-balanced --pose padPinch,cylinderGrip --focus hand`。

- `tests/test_hand_contacts.py` 检查指腹间距、手指到道具表面的距离、整手三角形对道具的穿插和手部自交。各身体、双手及不同握姿的读数取当前测试结果。
- 握姿是所有身体共用的一组角度，拇指在手的局部坐标里也处处相同。手腕接缝的修正量一直伸到拇指根，第一掌骨和近节的皮肤环随前臂的粗细和方向移动；关节跟着环心走时，腕粗的身体拇指会插进道具。所以 `skeleton` 用不受修正的指节求出模板手的整体摆放，手指关节都取模板的位置，拇指两个关节再加一个固定偏移 `THUMB_SEAT`（`sotaigen/rig/skeleton.py`，修正在中位身体上把它们移到的地方）。改前臂或手腕的形体不影响握姿，改 `THUMB_SEAT`、模板或握姿角度后要重跑手部测试。
- 拇指第一掌骨绕局部 Y 轴滚转，其余关节配合绕局部 Z 弯曲。参考结构为拇指对掌时的掌骨旋转与握持时的相对位置。数值是针对现有网格拟合的端姿。CMU 的五段动作没有手指动捕。[对掌实测](https://pubmed.ncbi.nlm.nih.gov/28888568/) · [握持时的拇指基底关节](https://pmc.ncbi.nlm.nih.gov/articles/PMC3940759/) · [第四、五掌骨运动测量](https://pmc.ncbi.nlm.nih.gov/articles/PMC3788642/)

**掌弓与表演手势。** 每侧用一个 `PalmCup` 近似第四、第五掌骨共同形成的掌弓。转轴沿腕至中指指根，掌面蒙皮从中指侧到小指侧逐渐跟随。无名指和小指保留独立的指节控制，小指根距轴较远，同角度下移动更多。模板、UV 和每顶点四权重的约定不变。放松、指向、挥手和轻触使用逐指的屈伸与张开角度，作为编辑器和 GLB 检查姿势。`littleOpposition` 检查拇指和小指指腹相向，`sphereGrip` 与 `thinCylinderGrip` 检查五指远节贴近道具，球和细柄的半径分别是掌长的 0.40、0.18 倍。静态姿势和接触回归覆盖全部身体的双手，接触距离和自交都量导出的三角形。同机位对照用同一个 `review sheet` 命令换姿势。[掌骨测量](https://pmc.ncbi.nlm.nih.gov/articles/PMC3788642/) · [手势绘画参考](https://www.proko.com/course-lesson/how-to-draw-expressive-hands)

**动态抓握。** `uv run sotaigen_dev/motion/clips.py glb female-long --clip cylinderPickup -o build/reports/motions/pickup.glb` 输出 3 秒、30 Hz 的拾取和放回动画，参考圆柱随片导出。靠近时从掌根张开虎口，拇指末节只轻弯，随后掌根转向手柄，近节与末节依次合拢。测量三个握姿中最接近道具的拇指指腹面，比较其朝向与道具表面朝内的法线：标准柄、细柄、球体的夹角在各身体上相同。抓稳后道具随腕移动，放回原位后松开。`--clip handGreeting` 输出空手挥动的动画。采样验证包括整只手的三角面与圆柱之间的最小距离、手部自交和持物时手相对圆柱的位移，Python 蒙皮下手不碰圆柱。这两段是手工编排的样片，握姿随身体的掌长缩放。[真人接近物体时的手形研究](https://journals.physiology.org/doi/full/10.1152/jn.1998.79.3.1307)

**手部限制：** `female-shortbust` 的 `littleOpposition` 在拇指根部有局部压扁面，需同时查看位置与观感，不能只看计数。
