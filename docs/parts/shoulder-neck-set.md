# 肩颈的前后对位

现象和取舍见[动态解剖卡](../motion/shoulder-neck-set.toml)与[肩腋决定](../DECISIONS.md#肩腋与胸侧)。

## 现状

`shoulderSetback` 是可选毫米规格项，范围 0–0.10 T，默认 0。它把肩峰、肩关节、肘和腕一起后移，相关体块、贴合与骨骼跟随；典型身体不设置此项。

- 腋窝凹面跟随后移量的 85%（`POCKET_FOLLOWS`），保持前后襞连接。
- `scapular_masses` 在胸背、胸侧各提供一块连接肩部的体块，至 0.06 T 后移时达到全量，小后移按比例生效。
- `setback_cap_share` 使肩顶跟随上臂的权重在关节前 0.05 T 起淡出，0.10 T 外留给肩带，避免远处胸前皮肤随上臂转动。

## 验证与限制

检查静止、垂臂、侧举、前抬和屈肘的正面、侧面及斜后视角，重点看后腋细褶、上胸折痕、肩顶轮廓与手髋接触。0–0.10 T 是模型的工程范围，不是人体中立姿态的测量范围。

侧举 72° 的后腋褶和前抬时侧面肩顶弧线仍需评估。随机参数组合、IPC 导出、后移身体的 `.blend` 与 GLB 驱动，以及垂臂卡的完整现象均未充分验证。上胸前缘独立控制、动态肩带前伸后缩、头颈整体前后位置及颈柱转折控制尚未实现。动态滑动与头颈控制在[卡片](../motion/shoulder-neck-set.toml)中留待单独设计；当前肩带采用锁骨联动，没有独立肩胛骨（见[肩带简化](shoulder-axilla.md#肩带简化)）。

## 依据

人体研究只支持“锁骨线本来就明显向后张开，放松时肩峰在胸廓后平面之前，后缩幅度有限”，给不出站姿下肩相对胸廓的毫米基准。具体见卡的 `girdle-rest`：

- 整尸研究的起始后缩约 32°，后缩到底再加 9°。
- 模型锁骨体块线与研究的解剖测量轴不是同一口径，不能把两者角度直接比较来证明 0.10 T 后移符合人体范围。
- 临床前肩角在不同论文里方向相反，不作目标数值。

所以范围靠看图和压力测试定，典型身体不因此改动。
