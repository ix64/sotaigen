# 躯干

腰腹过渡、胸下缘与上腹、腹前弧和后腰凹入。量法见 [PARAMETERS](../PARAMETERS.md)。

**还没解决：** 三项局部轮廓（`waistContourShift`、`abdomenFrontArc`、`lumbarHollow`）只在端点和少数组合上验证过，全参数组合和连续动画没有验证。端点与组合需在当前身体上完整复核。

## 腰腹过渡高低

可选参数 `waistContourShift`，缺省为 0，文件保存毫米；内部范围为 −0.06 T 至 +0.16 T，T 是躯干长（`sotaigen/params/spec.py`）。它在裆上 0.25 T 至 0.85 T 内改变胸廓、腹壁、骨盆碗和背部体块的纵向坐标，两端的位移和斜率归零。胸部软组织和肢体体块沿用原位置。它控制胸廓到骨盆之间的轮廓分配，收腰程度用腰宽另调；体表最窄点仅为诊断值，不是腰线定义，也不要求它单调移动。短直筒体型可以没有明显收腰。

体表最窄处、最低肋骨、髂嵴及两者中点是不同的测量位置。骨架仍使用原地标，偏移量不表示骨长变化。Wang 等在 111 人上比较了四种腰围测量位置，支持分开记录这些口径；该研究不提供本模型的参数范围或变形幅度。[四种腰围位置的原始比较研究](https://pubmed.ncbi.nlm.nih.gov/12540397/)

`calibrated(p)` 的 `L["waist"]` 是随控制移动的宽度测量位置，`landmarks(p)` 保留绑定用的原地标。先校准中性腰宽和胯宽，再只在移动区域内补偿横向尺度，保持腰宽和胯宽的 ±2% 契约。缺少参数与显式零值的场值逐项相同。

贴合先保留中性结果，再局部贴到新曲面；骨盆下方保持原网格，腋下交界通过相邻五圈淡出。局部性和参考皮肤绑定用于隔离腰腹控制对骨盆及姿势的影响，详见下文[贴合](#贴合)。

测试检查过渡上下段的宽度变化、局部性和 UV，不要求全局最窄点移动；翻面、塌陷与拉伸限制和别处相同。回归命令为 `uv run sotaigen-dev test tests/test_body.py tests/test_wrap.py tests/test_editor.py -k "waist_height or waist_offset or waist_transition or slider or round_trip"`。

### 编辑器里的腰腹过渡高低

体块／腰腹组的“腰腹过渡高低”设置 `body.waistContourShift`，参数文件缺少此项时显示 0。数字输入和 v2 文件使用毫米，范围由躯干长换算（`sotaigen/data/sliders.json`、`sotaigen/params/spec.py`）。它改变胸廓到骨盆之间的轮廓分配，全躯干最窄点的位置由它与腰宽、胯宽等控制共同决定。

### 贴合

`waistContourShift` 非零时，先按中性曲面做地标变形、投影与解折叠，再从中性网格局部贴合新曲面。移动区为裆上 0.25 T 至 0.85 T，躯干与手臂交界的影响在相邻五圈网格内淡出；手脚接缝固定。只对局部顶点做 30 轮曲面投影，其中前 24 轮带切向松弛；随后只在移动区内解折叠。区外顶点保持原位，头部与手脚沿用原生成路径。

网格从中性位置直接贴到新曲面，不另加搬移最窄点的约束。验证时同时检查下腹权重与骨盆蒙皮，避免局部轮廓控制改变绑定。

`test_waist_transition_redistributes_the_trunk_without_moving_the_pelvis` 在成品网格面边上取水平交点，检查过渡上下段的宽度变化。边界回归检查骨盆下方、手脚与头部的顶点逐项不变、无翻面或越中线，并保持现有 UV 拉伸与密度上限。

## 胸下缘与上腹衔接

乳房是坐在胸壁上的厚度场（[胸部](chest.md)），胸下缘与上腹的衔接由它的下皱襞和胸板的下缘决定，这里没有单独的参数或融合。

## 腹前弧与后腰凹入：实测距离控制

两个控制接入生成器与编辑器。它们描述局部表面弧度，不是内部椭球半径，也不是相对某个身体的任意强度。Cornell 的 2,488 名女性扫描研究将腹部突出与腰胯轮廓、臀部突出分开分析，支持把前腹轮廓独立描述；研究不提供本模型的参数范围。[原始研究说明](https://bodyscan.human.cornell.edu/currentPrint.html)

**测量口径。** 在站姿模型的正中矢状截面 X=0 上，取裆高以上 0.25 T 和 0.70 T 的前、后表面点，分别连直线。在 0.45 T 高度，量表面相对各自连线沿 Y 方向的距离，不是到斜线的最短距离。T 是裆部到颈窝的模型长度。三个高度是明确的模型约定，不是从肋骨、髂嵴或椎体检测出的解剖地标，也不随 `waistContourShift` 移动。NHANES 的腹部矢状径则在仰卧姿势的髂嵴高度测量，不能将其人体数值套用到这里。[测量手册 §3.4.9](https://wwwn.cdc.gov/nchs/data/nhanes/public/2013/manuals/2013_anthropometry.pdf)

- `abdomenFrontArc`：腹前壁向前凸出为正，向内收为负。零表示测量位置落在前侧连线上；可调范围 −0.03 T 至 +0.02 T。
- `lumbarHollow`：后腰相对后侧连线向内凹入的距离，可调范围 0 至 0.06 T。零表示测量位置落在线上；它不改变骨盆倾角。
- 此处总厚度为前、后表面的间距，作为成品读数。整体侧面还受上下连接点的位置及胸廓、骨盆形体影响。

范围是生成器的工程覆盖范围，不是人体正常范围或人群统计。缺少参数表示没有强制指定该测量目标，编辑器读取当前曲面的实测起点；显式零值有几何含义，不能按“未设置”处理。`waistDepth` 留作基础体块输入，编辑器里没有它的独立滑块；两个新参数直接约束成品的距离比例。

**形变与绑定。** 在融合后的完整曲面上作可逆的局部 Y 坐标变换。前后半区独立，左右及高度坐标不变；上下锚定截面、Y=0 测宽平面不变，侧方渐隐。局部性需同时检查腋下衔接圈、手脚与关节环。模板先贴合没有这两个目标的参考曲面，再映射到目标曲面，保持顶点身份。最终权重在逆映射恢复的参考皮肤上计算，骨架沿用成品地标。

参考皮肤用于隔离轮廓控制对权重的影响；下蹲塌陷仍按原阈值检查。裁切面需传递到底层参考场，以保持头部的去裁切流程正确。

**验证。** 分别量场与成品三角网的目标误差；覆盖端点、内收和深腰窝组合，检查贴合、UV、检查姿势塌陷及腿过中线。当前身体的完整组合验证仍待完成。

`hipFrontExcess`（`sotaigen/form/checks.py`）只作侧面诊断，不参与 `field_failures` 的失败判定。调腹前壁会影响前缘采样，不能把胯前缘与胸前缘的次序作为自动调整腹部的目标。

复测：`uv run scripts/abdomen_study.py --meshes`；出图：`blender -b --factory-startup -t 2 --python blender/review/abdomen_render.py`。曲面、逆映射、裁切隔离、实际绑定与成品目标的回归在 `tests/test_abdomen_profile.py`。外部目标的参数与图像保留在项目之外。

### 编辑器里的腹前弧、后腰凹入与总厚度

体块／腰腹组的 `abdomenFrontArc`、`lumbarHollow` 为绝对测量目标，定义见上文。数字输入和 v2 文件都使用 mm；缩放身高工具会同比缩放这些毫米值，躯干长工具也会保持它们占躯干长的份额（`sotaigen/params/tools.py` 的 `with_torso_length`）。零是连接线上的位置，不表示恢复默认。两个目标可独立设置。

起点值来自 `/api/body` 返回的 `abdomen.reference`，成品读数来自 `abdomen.measured`（三角网求交）。尚未生成且文件没有显式目标时，显示未知值并暂停这两个滑块，避免把起点误写成零。实测缓存以当前毫米规格为键；切换体型、导入文件、改变身高后不沿用旧读数。设置目标不自动改变另一项。总厚度只显示，没有“腰厚”滑块。

## 肩、胸和背的体块保留多少

看 toon 的两色：一个结构只有在能改变轮廓或交界线的大形时才保留。

| 结构 | 处理 | 为什么 |
|---|---|---|
| 三角肌 | 留，关节上方是圆帽，沿上臂拉长并慢慢收窄，上端盖过上臂骨的圆端 | 决定肩的轮廓。顶上是椭球尖端时肩峰处是硬角；收得太快时前抬肩头像球，下面有一级台阶；够不到上臂骨圆端时，圆端顶出斜方肌的线成肩峰小角，外侧留一道凹（[肩峰小角](shoulder-axilla.md#肩峰小角)，取舍见[肩腋卡](../motion/shoulder-chest.toml)） |
| 斜方肌 | 留，一个斜面 | 决定颈到肩的线 |
| 胸廓和背阔肌 | 留，合成从腋下到腰的一面墙 | 胸廓向上收得太快时，侧面朝上受光，阴影到最宽的肋骨才突然开始 |
| 胸部 | 乳房是胸壁上的厚度场（[胸部](chest.md)） | 单独融合的体块边缘会在胸侧画出一圈环，交界线在那里有缺口 |
| 锁骨 | 随 `definition`，`definition` 低时几乎不可见 | 和斜方肌共用宽融合时，埋着也会鼓起，胸骨两侧有两个包 |
| 胸肌、肩胛、竖脊肌的分块 | `definition` 低时不单独表现；胸肌另见[男性肌肉](male-muscle.md) | 两色下没有信息，只产生噪点 |
