# 坐标和拓扑

[English](../en/reference/coordinates-topology.md)

冻结的约定 1：所有身体同一套拓扑，顶点顺序相同。给一个身体做的东西（头、衣物、改过的权重）按顶点序号就能用在另一个身体上。

## 坐标

| 用在哪 | 轴 | 单位 |
|---|---|---|
| 本工具内部、`.blend`、参数文件里的长度 | Z 朝上（离地高度），前方是 -Y，穿着者左侧是 +X | mm（`.blend` 里是 Blender 的米，数值同 GLB） |
| GLB | 本工具的 `(x, y, z)` 写成 `(x, z, -y)`：+Y 朝上，正面朝 +Z，穿着者左侧是 +X，和 VRM 相同 | m |

GLB 的换算是纯旋转，面的绕向不变。身体左右对称：右侧是左侧镜像。

- **顶点顺序：** 先是模板源网格的 8781 个，再是头的 3313 个（序号 8781 起），再按批次接后加的环（肘、膝 400 个，肩、腋 182 个）。**编号只追加：** 以后加环也排在最后，已有的序号都不变。
- **面：** 四边形和三角形混合，就是上表那份面列表，所有身体相同。GLB 里四边形按模板上较短的对角线切成三角形，所以所有身体也共用一份三角形列表。
- **UV 接缝的副本：** GLB 的皮肤在 UV 接缝处复制顶点，副本排在全部原顶点之后，`extras.sotaigen.splitFrom` 写每个副本的原顶点。前面的顶点和上表的顺序相同。`.blend` 不复制顶点，UV 存在面角上。
- **UV：** 所有身体同一套 UV。
- **头的区块和颈环** 是换头接口的一部分，见[换头的接口](head-interface.md)。
