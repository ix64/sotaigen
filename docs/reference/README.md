# 对外约定

[English](../en/reference/README.md)

这里是 sotaigen 对下游的承诺：下游可以依赖的名字、结构和单位，以及它们怎样变。别的都可能随版本变，包括输出的措辞、几何本身、参数的范围和规则。

## 冻结的约定

| # | 约定 | 说明 |
|---|---|---|
| 1 | 模板的拓扑和顶点顺序 | [坐标和拓扑](coordinates-topology.md) |
| 2 | 骨骼的名字、父子关系、顺序、局部轴和静止姿势，`.blend` 里的控制骨命名 | [骨骼](skeleton.md)、[.blend](blend.md) |
| 3 | 参数文件的结构、参数名和单位 | [参数文件](parameters.md) |
| 4 | GLB 的 `extras.sotaigen` 的字段、两张驱动表的结构、诊断的代码，`.blend` 的 `rig["sotaigen"]` 同样 | [GLB](glb.md)、[.blend](blend.md)、[诊断](diagnostics.md) |
| 5 | 典型身体的名字 | [典型身体](bodies.md) |
| 6 | 颈环和头部挂点 | [换头的接口](head-interface.md) |
| 7 | 命令行的子命令、参数和退出码 | [命令行](cli.md) |

不在约定之内的：修正形状的目标名（只保证和驱动表一致）、检查姿势、占位的五官、耳和头发（表情只约定名字）、参数的范围和规则、输出文字、几何。

## 版本

- 包的版本号按[语义化版本](https://semver.org/lang/zh-CN/)。`sotaigen` 和 `sotaigen-blender` 一起发布，版本号相同。
- **约定从 0.1.0 起冻结。** 语义化版本允许 0.x 随时改，这里的承诺比它严：0.x 期间也不破坏上面 7 条。
- 必须破坏约定时（为了新功能，不为了重新命名），0.x 期间升次版本号（0.1 → 0.2），1.0 以后升主版本号；写进 CHANGELOG，附迁移说明。和 Cargo、npm 对 0.x 的读法相同：0.1.x 之间互相兼容。
- 加东西不算破坏：新的可选参数、新的诊断代码、新的修正组、新的字段。读者要容得下不认识的字段和代码。
- 每种文件另有自己的 `format` 和 `version`（参数文件、GLB、`.blend`），只在该格式的含义变时加一，和包的版本号分开。读者拒绝比自己新的 `version`。

## 兼容到哪一步

- 同一版本：同样的参数得到逐字节相同的 GLB，不论从命令行、API 还是编辑器生成。前提是同一份锁定的依赖（`uv.lock`）。
- 跨版本：参数文件总能打开、含义不变。**几何随形体改进而变化**：同一份参数可能得到不同的身体。要追溯时看文件里的 `generator`（包版本和绑定指纹）。
- 下游的东西（换来的头、衣物、改过的权重）按顶点序号和骨名对位，所以跨版本仍然对得上，只是位置会随形体变。

## 规范文本

英文版是规范文本。名字、键、代码、单位以 `tests/contracts/` 的金样为准，这里的表由 `sotaigen_dev/reference.py` 从金样生成，`tests/test_contracts.py` 拿代码对照金样。文字和金样不一致时以金样为准。
