# 已知限制

[English](../en/reference/limitations.md)

下面列出 0.1.0 的已知缺陷和待验证项目；修复后的几何变化按[兼容政策](README.md#兼容到哪一步)处理。

## 形体和变形

- **腹股沟：** 屈髋时小腹中央和大腿根的相压只做到一部分，腿根中央偏硬；屈髋 85° 以上还有一圈折痕，深屈髋会穿插。
- **肩和腋下：** 高侧举时腋下有一段长斜面，上臂内侧凹陷；后腋襞有小折痕；前举 95° 和 130° 时腋下被压住的地方多出几条折边。不合理的复合欧拉角会把上臂转进躯干，带大扭转的复合姿势里修正形状只淡到一半左右。
- **干净范围比人的活动范围小：** `.blend` 的关节极限按真人的活动范围设，网格在其中一部分角度内才好看；超出干净范围的姿势会有折痕或塌陷。
- **赛璐璐的明暗线：** 颈部有一个小台阶，脚踝和手腕处的分界不顺，都来自几何，不是导出造成的。
- **衣物没有验证过：** 还没有拿标准衣物在检查姿势上看过穿插，也还没有衣下可隐藏的区域和衣物对位用的地标。
- **手臂粗的身体垂臂：** `female-heavyarm` 手臂垂到 24°（`armsDown`）时，前臂穿进腰侧。
- **只有静态的接触：** 默认的修正形状是雕塑和隐式场做的；按接触求解的 IPC 接触表是实验特性（`sotaigen[contact]`），只进 GLB，不进 `.blend`。不是每个身体都烘得出来，烘不出来的那张表退回默认修正，文件里写明（`contact.failed`）：手臂粗的身体在手臂贴着身体的地方（`female-heavyarm`、`male-heavyarm` 的垂臂表，`male-wideheavyarm` 的肩腋表），`female-smallbust` 的垂臂表（求解器的数值失败），以及 8 个矮小、偏瘦或男性身体的腹股沟表（两腿屈到 50–95° 高低不一时塌一个面，或胯底中线小区穿插过多）。

## 文件和工具

- **驱动读欧拉角：** 辅助骨的联动按 `Rz · Ry · Rx` 的欧拉角算。从四元数换回欧拉角时，`y` 的绝对值超过 90° 会得到另一组等价角度，旋转相同，肩胛的联动却不同。
- **普通导入器不读驱动表：** Blender 的 glTF 导入和一般的播放器不读 `extras.sotaigen` 的两张驱动表，只播放烘焙好的动画；要在别处摆姿势，就自己实现[驱动表](glb.md#辅助骨的驱动表)，或者用 `.blend`。
- **没有 VRM：** VRM 1.0 导出还没做。
- **参数文件不能直接出图：** 看图工具只认自带的身体；下游的参数文件先生成 GLB 或 `.blend` 再看。
- **编辑器** 同一时间只生成一个身体，第二个页面的请求会取消第一个；它仅供运行服务的计算机访问。

## 平台

- 支持 macOS 和 Linux，不支持 Windows。
- 到目前只在 Apple Silicon 的 macOS 上跑过：Blender 5.2.3、Chrome、Apple 的 GPU。别的 GPU 和 Linux 上的 Blender 只在 CI 的配置里写了，还没跑过。
- 同样的参数得到同样的字节，前提是同一份锁定的依赖（`uv.lock`）。
