# 典型身体

[English](../en/reference/bodies.md)

冻结的约定 5：典型身体的名字。名字是 `<性别>-<组>`，`sotaigen.typical(名字)` 和编辑器的起点都按它找。参数会随版本改进，名字不变；金样在 `tests/contracts/bodies.json`。

组名按比例和体格描述，男女共用：Q版 `chibi`、小巧 `compact`、纤细 `slim`、修长 `long`、匀称 `balanced`、圆润 `rounded`。它们是不同年龄段真人统计的风格化，不对应任何具体角色。

测试身体（`sotaigen/data/bodies/<性别>/test/`）只给本工具的测试用，名字和参数都不在约定之内。
